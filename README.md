# SpecAnalyzer - 地质光谱数据分析工具

基于 Qt6/C++17 的光谱数据分析工具，用于地质调查中光谱曲线的可视化、峰值检测和半高宽（FWHM）分析。

## 功能

- **CSV 光谱数据导入**：支持批量导入，自动识别 UTF-8/双重编码
- **光谱曲线可视化**：滚轮缩放 X 轴、Shift+滚轮缩放 Y 轴、拖拽平移、双击复位
- **Savitzky-Golay 平滑**：可配置窗口大小和多项式阶数
- **ALS 去本底**：非对称最小二乘法基线扣除，可调平滑度和不对称性
- **自动峰值检测**：基于 Topographic Prominence 算法，自动找峰并计算半高宽
- **峰值过滤**：支持最低强度和半高宽区间过滤
- **峰值追踪导出**：选择目标峰，批量分析多个文件中对应峰的值
- **结果导出**：导出所有峰值的波长、强度、半高宽（宽表格式）

## 算法

### 峰值检测
1. 邻域局部极大值检测
2. Topographic Prominence 计算（峰高出通往更高峰的最低点的高度）
3. Prominence 阈值过滤（默认最大强度 2%）
4. 按波长升序排列

### 半高宽（FWHM）计算
1. 找到峰两侧谷底（局部最小值）
2. 计算半峰高度 = peak / 2
3. 在谷底范围内搜索半峰穿越点（线性插值）
4. 找不到穿越点时用谷底波长兜底

### ALS 去本底
非对称最小二乘法迭代拟合基线：峰上方点给低权重 (p≈0.01)，下方点给高权重 (1-p≈0.99)，λ 控制基线平滑度。

### Savitzky-Golay 平滑
最小二乘多项式拟合的卷积平滑，保持峰形特征。

## 构建

### 依赖
- Qt 6.5+ (Core, Gui, Widgets, Charts)
- CMake 3.22+
- C++17 编译器

### macOS
```bash
brew install qt@6
cmake -B build -DCMAKE_PREFIX_PATH=/opt/homebrew/opt/qt
cmake --build build
```

### Windows / Linux
```bash
cmake -B build -DCMAKE_PREFIX_PATH=/path/to/qt6
cmake --build build
```
