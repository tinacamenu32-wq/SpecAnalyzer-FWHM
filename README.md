# SpecAnalyzer - 地质光谱数据分析工具

基于 Qt6/C++17 的光谱数据分析工具，用于地质调查中光谱曲线的可视化、峰值检测和半高宽（FWHM）分析。

## 功能

- **CSV 光谱数据导入**：支持批量导入，自动识别 UTF-8/双重编码
- **光谱曲线可视化**：滚轮缩放 X 轴、Shift+滚轮缩放 Y 轴、拖拽平移、双击复位
- **Savitzky-Golay 平滑**：可配置窗口大小和多项式阶数
- **ALS 去本底**：非对称最小二乘法基线扣除，可调平滑度和不对称性
- **自动峰值检测**：基于 Topographic Prominence 算法，自动找峰并计算半高宽
- **峰值过滤**：支持最低强度和净峰积分面积区间过滤
- **峰值追踪导出**：选择目标峰，批量分析多个文件中对应峰的值
- **结果导出**：导出所有峰值的波长、强度、半高宽原始值（nm）和净峰积分面积（宽表格式）

## 算法

### 峰值检测
1. 邻域局部极大值检测
2. Topographic Prominence 计算（峰高出通往更高峰的最低点的高度）
3. Prominence 阈值过滤（默认最大强度 2%）
4. 按波长升序排列

### 半高宽（FWHM）计算
1. 找到峰两侧谷底（局部最小值）
2. 计算半峰高度 = 峰顶处局部基线 +（峰强度 − 局部基线）/ 2
3. 在谷底范围内搜索半峰穿越点（线性插值）
4. 找不到穿越点时用谷底波长兜底

### ALS 去本底
非对称最小二乘法迭代拟合基线：峰上方点给低权重 (p≈0.01)，下方点给高权重 (1-p≈0.99)，λ 控制基线平滑度。

### Savitzky-Golay 平滑
最小二乘多项式拟合的卷积平滑，保持峰形特征。

### 完整峰净积分面积

- 数据路径：原始光谱 → 可选 S-G 平滑 → 可选 ALS 去本底 → 完整峰面积分析。
- **独立峰**：用峰区间两端连接的直线作为局部基线，积分 `max(强度 − 局部基线, 0)`。跨零区间在线性插值零点处分段，负值不抵消正面积。
- **峰边界**：从峰顶向左右搜索连续 3 个近背景采样点；独立峰背景容差为净峰高的 0.1%，重叠峰群为 0.005%，并结合局部噪声估计（噪声容差上限为净峰高的 2%）。两端重新建立局部基线，因此是有限观测区间上的净面积，不代表数学上延伸至无穷的峰尾。
- **重叠峰**：按检测到的候选峰数进行非负多高斯联合拟合，共用峰群两端的局部直线基线。各分量分别在实际积分区间内积分，不重复分配整片峰群面积。组间谷底高于较低净峰高的 10%，或没有独立谷底时视为需要联合拟合的峰群。
- 高斯分峰属于模型估计，尤其是肩峰。最多联合拟合 8 个组分；要求采样点数至少为组分数的 5 倍、拟合收敛、相对加权 RMS 误差不超过 5%，并检查参数退化、峰宽约束及组分可分辨性。检查通过并不等于已证实真实峰形；完全重合或未检出的隐藏峰不能凭空确定峰数。
- 边界触及采集范围时标记“可能截断”，不对缺失峰尾自动补齐。分峰失败时保留峰位等信息，面积留空并导出原因；失败或可能截断的面积不参与 RSD。
- 界面与两个导出入口都先联合分析完整候选峰集，再执行强度/面积过滤。面积不可用的峰仍保留供检查，不按零面积处理。
- CSV 每个峰占 7 列：波长、强度、半高宽原始值（nm）、净峰积分面积、积分左边界、积分右边界、面积计算状态。面积单位为“强度单位 × nm”。半高宽原始值仍沿用观测曲线上的半高宽算法，重叠峰的该列不是拟合组分的半高宽。
- 批量匹配默认容差为 0.5 nm，同一文件的不同峰不会聚合成一列，同一检测峰也不会重复写到两列；谱线特别密集或漂移较大时仍需核对峰位匹配。
